      PageSpeed API Key

      Enables in-page PageSpeed test results. Paste the API key from Google Cloud Console (the same project where you enabled PageSpeed Insights API). Stored in your browser only.

      GA4 Property ID

      Your Google Analytics 4 property ID (numbers only, e.g. 123456789). Find it in Google Analytics under Admin > Property Settings. Add it to Vercel as the environment variable GA4_PROPERTY_ID.

      One-time setup: OAuth credentials

      You only need to do this once. These steps create the OAuth client that lets the Connect button work.

      1

      Open Google Cloud Console

      Go to console.cloud.google.com, open your project, then go to APIs & Services > Credentials.

      2

      Create an OAuth client

      Click Create credentials > OAuth client ID. Choose "Web application." Under Authorized redirect URIs, add exactly: https://www.sabraandcompany.com/api/google-callback

      3

      Copy the Client ID and Secret

      After creating, copy the Client ID and Client Secret. You'll add these to Vercel in the next step.

      4

      Add to Vercel environment variables

      In your Vercel project settings under Environment Variables, add: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, and GA4_PROPERTY_ID. Redeploy after saving.

      5

      Click Connect with Google above

      Once the env vars are deployed, click the Connect button at the top of this tab. You'll sign in with Google and grant access. You're done.

      Your PageSpeed API key is stored only in your browser. Google OAuth tokens are stored in secure httpOnly cookies on the server and never touch your browser's localStorage. Disconnecting clears all tokens immediately.
