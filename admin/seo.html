    Recommendations

    Prioritized improvements from the last audit. High priority items have the most impact on search visibility.

      Setup & configuration

      Connect live data sources. Start with PageSpeed; it only needs a free API key and takes two minutes.

      PageSpeed API key (optional)

      PageSpeed works without a key. If you run many tests per day and start hitting rate limits, add a free key here to remove them. Saved in your browser only.

      How to get a PageSpeed API key

      1

      Open Google Cloud Console

      Go to console.cloud.google.com and sign in with your Google account.

      2

      Create or select a project

      Click the project dropdown at the top and create a new project (for example, "Sabra SEO"). Free tier is enough.

      3

      Enable the PageSpeed Insights API

      Search for "PageSpeed Insights API" in the API Library and click Enable.

      4

      Create a key

      Go to APIs & Services > Credentials, click Create credentials > API key. Copy the key.

      5

      Paste it above and save

      Paste the key into the field at the top of this tab and click Save. Then go to the PageSpeed tab and run your first test.

      Search Console

      Search Console data (keywords, impressions, clicks) requires OAuth and cannot be accessed with a plain API key. For now, export a CSV from Search Console and paste it into the Keywords tab. A server-side integration can be added later if needed.

      Your API key is stored only in this browser via localStorage. It is never sent to any server other than Google. Clearing your browser data will remove it.
